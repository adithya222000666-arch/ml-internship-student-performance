Predicting Final Secondary Student Achievement (G3)

This intelligent decision-support web application uses a supervised machine learning pipeline trained on the real UCI Student Performance (student-mat) dataset. It analyzes 30 non-grade demographic, socio-economic, and behavioral factors to predict a student's final academic grade on the official 0–20 scale.
